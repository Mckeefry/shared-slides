Scheduled Usage

Automated or recurring prompt patterns detected

Detection method: same user + same prompt text, run 3+ times with a coefficient of variation ≤ 0.40 on inter-run intervals and consistent day-of-week alignment.

What the data shows

Only 3 confirmed scheduled patterns were detected across 99,647 initial prompts. This is a significant finding: the vast majority of usage is organic and manual, not automated. Users are actively engaging with the tool rather than relying on automated runs.

Scheduled pattern 1 — Weekly, every Monday

  • Cadence: Every 168 hours — every Friday, 100% day consistency
  • Run count: 3 confirmed runs
  • Intent: Process / Task Management
  • Prompt: Quarterly Task Review — review all active tasks, update or delete as needed
Scheduled pattern 3 — Daily rotation
  • User: Tj Hinton (Renewals Specialist, Americas)
  • Cadence: Every 24 hours (daily refresh), 4 confirmed runs
  • Intent: Risk
  • Prompt: Sentiment analysis for Top 20 ATR customers (6–18 month window) using 4-day rotation

Key insight: Scheduled use is rare and purpose-built. These prompts represent high-value recurring operational reports that are strong candidates for native scheduled delivery inside the tool.

Adoption Actions

Recommendations based on initial intent demand

1) Build intent-first prompt packs

Create guided packs for Risk, Pipeline, Deals, Customers, and Sales so users start with strong first prompts.

2) Launch role-based onboarding tracks

Prioritize Renewals Specialist and Renewals Manager tracks because they dominate core intent usage.

3) Monday-first enablement cadence

Release weekly kits on Monday morning focused on risk triage, pipeline prioritization, and deal review.

4) Customer and deal acceleration workflows

Package reusable prompts for account briefings, deal diagnostics, and next-best-action recommendations.

5) Region-specific playbooks

Localize Americas-first templates, then tune risk/deal variants for EMEA and APJC operating models.

6) Improve intent telemetry

Track intent at run-time and standardize Region and Title values to monitor adoption lift by question type.

Expected outcome: faster first-response value, higher quality initial asks, and stronger adoption growth aligned to business-critical question types.
